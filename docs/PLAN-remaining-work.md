## 1. 优先级原则

1. **工程风险优先**：两个真实入口零覆盖率是最大隐患，且它让后续所有工作都缺少安全网。
2. **先修数据模型，再做展示**：截图标注卡在数据模型，不先扩展 `VisualViolation` 就无法实现。
3. **每个工作流独立可交付**，不要求一次全做完。
4. **不做无验收门的工作**：每项都必须有可执行的通过/失败判据。
